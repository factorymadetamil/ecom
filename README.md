# ShopHub - E-Commerce Platform

A modern, fully-featured e-commerce application built with React, TypeScript, and Tailwind CSS.

## Features

- 🛍️ **Product Catalog** - Browse, search, and filter products
- 🛒 **Shopping Cart** - Add, remove, and update cart items
- 🔐 **Authentication** - Sign up and sign in functionality
- 💳 **Payment Processing** - Complete checkout flow
- 👥 **Admin Dashboard** - Role-based admin panel
- 📱 **Responsive Design** - Mobile-first approach
- 🎨 **Modern UI** - Beautiful, accessible interface

## Tech Stack

- **Frontend**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS, Shadcn UI components
- **Icons**: Lucide React
- **State Management**: React hooks, localStorage
- **Build Tool**: Vite
